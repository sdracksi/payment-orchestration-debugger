# Release v0.3.0 - Transactions API

## Objective

Build the first production-ready Transactions API for the Payment Orchestration Debugger.

This API will expose transaction data for the future React frontend and support filtering, pagination, and JSON serialization.

---

## Scope

### Endpoints

- GET /api/v1/transactions
- GET /api/v1/transactions/:id

### Features

- Transaction listing
- Transaction details
- Filtering
  - Status
  - Gateway
  - Merchant
- Pagination
- JSON serialization
- Request specs
- Seed data

---

## Out of Scope

- Authentication
- Authorization
- Creating transactions
- Updating transactions
- Deleting transactions

These will be implemented in future releases.

---

## Success Criteria

- API returns JSON
- Filters work correctly
- Pagination works
- Request specs pass
- Seed data is available
